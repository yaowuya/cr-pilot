**F-001：`createPiReviewer` 构造即创建隔离临时目录，测试注入假会话时同样创建且不清理**

- 失败场景：长期反复运行测试持续累积空目录。生产环境每进程只创建一次并复用，影响限于测试卫生。

**F-002：GitLab payload 不含代码这一限制在 README、运行时错误信息与评审文档三处并列维护**

- 证据：`README.md`（注意事项段）、`src/app.ts:87-93` 的 `describeMissingCode`、`review.md#评审顺序与抽查路径` 各自完整表述同一限制。

- 来源要求：`review.md` 建议抽查项；`design/backend.md#接口权限与兼容边界`。
- 建议修复方向：以 README 为权威说明，运行时错误信息保留指向性短句。
